Fregoli 1.0 is out. You can find it here: [pihme.github.io/fregoli](https://pihme.github.io/fregoli/) (source on [GitHub](https://github.com/pihme/fregoli), release and source archive under [fregoli/v1.0.0](https://github.com/pihme/fregoli/releases/tag/fregoli/v1.0.0)).

# What is Fregoli?
Fregoli is a web app you change by talking to it. The page stays open, you describe what you want, and the app changes in place. Under the hood every capability is a [Cordis](https://github.com/cordiverse/cordis) plugin that is mounted and unmounted in a live Node process, so nothing has to be restarted. The name comes from [Leopoldo Fregoli](https://en.wikipedia.org/wiki/Leopoldo_Fregoli), the quick-change artist: one performer, many appearances, no restart of the show.

Open it and you get a page, plus a small [Helferlein](https://github.com/pihme/helferlein) figure in the lower right. That figure is the chat. The chat goes to the Grok CLI when it is installed, otherwise to a simple stand-in. Grok gets tools to look at the page, load and unload plugins, highlight elements and wait for a click.

# What is in 1.0?
- **One update per reply.** The page stays as it is while the agent works, and one line in the chat shows what it is doing. When the reply is finished and the page has changed, the figure turns away, the page loads the result once, and the chat is still there.
- **Point.** Press **Point** at the top of the chat and click part of the page. Your message then names that element, so the agent knows what you mean.
- **Two fixes before the release.** A failed send no longer leaves the chat stuck on "Working…" (0.4.3), and a reply that repeats the previous one is no longer dropped, also after a server restart (0.4.4).

All 44 tests pass in CI. This is still an MVP: it works in principle, it feels clunky, and the first reply is usually very long. Making that first reply faster is planned for 2.0 ([#36](https://github.com/pihme/fregoli/issues/36)).

# How do I get it?
You need Node 22 or newer. Clone the repository, run `npm ci` and `npx tsx src/cli.ts`, then open http://127.0.0.1:8080/. For a real conversation, install the Grok CLI and sign in, or set `XAI_API_KEY`. There is also a Dockerfile; the image serves the page on port 8080. The release itself is a source archive.
